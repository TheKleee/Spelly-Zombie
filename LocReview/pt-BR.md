# Portuguese, Brazil (pt-BR) review sheet

File: `Assets/StreamingAssets/Loc/sz_loc_pt-BR.json`. Register: você with
the friendly imperative Brazilians actually use. Brazilian wording: salvar,
apagar, senha, de boa, pra valer. European Portuguese would differ in
several places (palavra-passe, ecrã); this file is Brazil only, as the
Steam box says.
